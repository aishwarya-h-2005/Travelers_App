# 🌍 Travelers - Full Stack Flutter App
A community platform for travelers to share posts and discover new destinations.

### 🚀 Key Features
* **Firebase Auth:** Secure Login/Signup.
* **Global Feed:** Real-time posts using Cloud Firestore.
* **Top Places:** Interactive destination discovery with Search.
* **Dynamic UI:** Beautifully responsive for Android, iOS, and Web.

### 🛠️ Tech Stack
* Flutter & Dart
* Firebase (Auth & Firestore)
